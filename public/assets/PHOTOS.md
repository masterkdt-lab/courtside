Nelson Ramos has no photo in the repo; his profile shows a monogram until KC supplies one.

Derived files live in `public/assets/derived/` and are generated by `npm run images`. Crops are declared in `scripts/make-images.js` with a named focal point; never crop by hand in CSS alone when a derived crop exists. EXIF metadata was stripped from the originals on 2026-10-05; run `scripts/strip-exif.js` on any new photo before adding it.
